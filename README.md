# Tsumi-Tsumi / つみつみ

## アプリ概要

Tsumi-Tsumi / つみつみは、タスクや予定を管理しながら、未完了タスクの積み上がり具合を「つみ度」として可視化するWebアプリです。

つみ度は、未完了タスク、締切、重要度、見積時間、診断結果をもとに計算されます。数値が高いほど、タスクが積み上がっていて注意が必要な状態を表します。

また、タスクの進め方タイプ診断の結果に応じて、自分に合った進め方のアドバイスを確認できます。今の状況を見える化し、次に何から取り組むかを考えやすくすることを目的としています。

## 主な機能

### Home画面

- 今日の日付を表示
- 今日のタスクと予定を表示
- 現在のつみ度を表示
- Home、Tasks、Calendar、Status、Diagnosisへのリンク
- 診断結果とつみ度に応じた「次の一手」を表示
- 保存データを初期サンプルデータに戻すリセット機能

### Tasks画面

- タスクの追加、編集、削除
- タスクの完了 / 未完了の切り替え
- 未完了タスク / 完了タスクのタブ切り替え
- タスク名、締切、見積時間、重要度の入力チェック
- 締切、重要度、見積時間、診断結果をもとにした自動優先度表示
- タスクidを使った安定した編集、削除、完了切り替え

### Calendar画面

- 予定の追加、編集、削除
- 予定削除前の確認メッセージ
- 予定編集時に入力フォームへ移動
- 予定名、日付、開始時刻、終了時刻の入力チェック
- 前の週、今週、次の週を切り替えられる週間カレンダー表示
- 今日の日付の強調表示
- 予定と締切タスクの区別表示
- 今日、1日後、3日後、7日後の推定つみ度表示

### Status画面

- 現在のつみ度カード
- 危険度ラベルの表示
- つみ度ゲージの表示
- 完了数、未完了数、達成率、残り見積時間の表示
- つみ度が高くなっている理由の表示
- つみ度に影響しているタスクの表示
- 診断結果に応じた進め方アドバイス

### Diagnosis画面

- タスクの進め方タイプ診断
- 7つの質問への回答
- 診断結果の保存
- 保存済み診断結果の表示
- 再診断
- 診断結果をHome画面とStatus画面のアドバイスに反映

## 起動方法

初めて起動する場合は、必要なパッケージをインストールします。

```bash
npm install
```

開発用サーバーを起動します。

```bash
npm run dev
```

実行後、ターミナルに表示されるURLをブラウザで開いてください。

## 発表・提出時の操作手順

発表や提出時は、以下の順番で操作すると主要機能を確認しやすくなります。

1. アプリを起動します。
   - `npm install` を実行します。
   - `npm run dev` を実行します。
   - ターミナルに表示されたURLをブラウザで開きます。

2. Home画面を確認します。
   - 今日の日付が表示されていることを確認します。
   - 今日のタスクと予定を確認します。
   - 現在のつみ度を確認します。
   - 各画面へのリンクから移動できることを確認します。

3. Tasks画面を確認します。
   - 未完了タスクと完了タスクのタブを切り替えます。
   - タスクを追加します。
   - 未入力や不正な値で入力チェックが表示されることを確認します。
   - 追加したタスクに自動優先度が表示されることを確認します。
   - タスクの完了 / 未完了を切り替えます。

4. Calendar画面を確認します。
   - 週間カレンダーを表示します。
   - 今日の日付が強調表示されていることを確認します。
   - 予定と締切タスクが区別して表示されていることを確認します。
   - 予定を追加します。
   - 追加した予定を編集します。
   - 予定を削除するときに確認ダイアログが表示されることを確認します。
   - 今日、1日後、3日後、7日後の推定つみ度を確認します。

5. Diagnosis画面を確認します。
   - 診断の説明を確認します。
   - 7つの質問に回答します。
   - 診断結果を保存します。
   - 保存された診断結果を確認します。
   - 必要に応じて再診断します。

6. Status画面を確認します。
   - つみ度カードを確認します。
   - 危険度ラベルとつみ度ゲージを確認します。
   - 完了数、未完了数、達成率を確認します。
   - つみ度に影響しているタスクを確認します。
   - 診断結果に応じたアドバイスを確認します。

7. データリセット機能を確認します。
   - Home画面下部の「データをリセット」ボタンを押します。
   - 確認ダイアログが表示されることを確認します。
   - リセット後、初期サンプルデータに戻ることを確認します。

8. 確認コマンドを実行します。
   - `npm run build` でビルドできることを確認します。
   - `npm run lint` でlint確認を行います。

## ビルド確認

提出前や動作確認時は、以下のコマンドでビルドできるか確認します。

```bash
npm run build
```

## lint確認

```bash
npm run lint
```

## データ保存について

タスク、予定、診断結果はブラウザのlocalStorageに保存されます。そのため、ページを再読み込みしても入力したデータは残ります。

Home画面の「データをリセット」ボタンを使うと、保存されているタスク、予定、診断結果を削除し、初期サンプルデータに戻せます。初期サンプルデータは、提出・発表時に各画面の表示を確認しやすい内容に整理されています。
