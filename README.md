# Tsumi-Tsumi / つみつみ

## アプリ概要

Tsumi-Tsumi / つみつみは、タスクや予定を管理しながら、未完了タスクの積み上がり具合を「つみ度」として可視化するWebアプリです。

つみ度は、未完了タスク、締切、重要度、見積時間、診断結果をもとに計算されます。数値が高いほど、タスクが積み上がっていて注意が必要な状態を表します。

また、タスクの進め方タイプ診断の結果に応じて、自分に合った進め方のアドバイスを確認できます。今の状況を見える化し、次に何から取り組むかを考えやすくすることを目的としています。

## 主な機能

### Home画面

- 今日の日付を表示
- 今日のタスクと予定を表示
- 現在のつみ度を表示
- Home、Tasks、Calendar、Status、Diagnosisへのリンク
- 診断結果とつみ度に応じた「次の一手」を表示
- 保存データを初期サンプルデータに戻すリセット機能

### Tasks画面

- タスクの追加、編集、削除
- タスクの完了 / 未完了の切り替え
- 未完了タスク / 完了タスクのタブ切り替え
- タスク名、締切、見積時間、重要度の入力チェック
- 締切、重要度、見積時間、診断結果をもとにした自動優先度表示
- タスクidを使った安定した編集、削除、完了切り替え

### Calendar画面

- 予定の追加、編集、削除
- 予定削除前の確認メッセージ
- 予定編集時に入力フォームへ移動
- 予定名、日付、開始時刻、終了時刻の入力チェック
- 前の週、今週、次の週を切り替えられる週間カレンダー表示
- 今日の日付の強調表示
- 予定と締切タスクの区別表示
- 今日、1日後、3日後、7日後の推定つみ度表示

### Status画面

- 現在のつみ度カード
- 危険度ラベルの表示
- つみ度ゲージの表示
- 完了数、未完了数、達成率、残り見積時間の表示
- つみ度が高くなっている理由の表示
- つみ度に影響しているタスクの表示
- 診断結果に応じた進め方アドバイス

### Diagnosis画面

- タスクの進め方タイプ診断
- 7つの質問への回答
- 診断結果の保存
- 保存済み診断結果の表示
- 再診断
- 診断結果をHome画面とStatus画面のアドバイスに反映

## 起動方法

初めて起動する場合は、必要なパッケージをインストールします。

```bash
npm install
```

開発用サーバーを起動します。

```bash
npm run dev
```

実行後、ターミナルに表示されるURLをブラウザで開いてください。

## ビルド確認

提出前や動作確認時は、以下のコマンドでビルドできるか確認します。

```bash
npm run build
```

## lint確認

コードの書き方に問題がないか確認する場合は、以下のコマンドを実行します。

```bash
npm run lint
```

## データ保存について

タスク、予定、診断結果はブラウザのlocalStorageに保存されます。そのため、ページを再読み込みしても入力したデータは残ります。

Home画面の「データをリセット」ボタンを使うと、保存されているタスク、予定、診断結果を削除し、初期サンプルデータに戻せます。初期サンプルデータは、提出・発表時に各画面の表示を確認しやすい内容に整理されています。
